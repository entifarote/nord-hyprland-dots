Nord hyprland dots.

If you want to use the config, tweak the used apps, shortcuts and file paths in hyprland.lua, hyprlock to your liking.

Stuff i use:

WM: Hyprland
Bar: Waybar
Font: JetBrains Mono Nerd
App launcher: Wofi
Lockscreen: Hyprlock
Terminal: Alacritty
Notification manager: Dunst
Shell: Fish
Music player: Cliamp
Wallpaper: Hyprpaper
